# 署名キー（SIGNING）

- 署名キーはプロジェクト内の `.local/scriptlet.keystore` に置き、debug / release の両方に使う（`app/build.gradle.kts` の `persistent` signing config、パスワード等は `.local/signing.properties`）。
- `.local/` は .gitignore 対象。キーストアとパスワードをリポジトリにコミットしない。
- 背景: 以前はビルドマシンのデフォルト debug キーストア（ホーム配下）で署名していたため、マシンが入れ替わるたびにキーストアが再生成され、APKの署名証明書が毎回変わっていた（v0.10.0 / v0.13.0 / v0.16.5 で全て別証明書だったことを実測）。署名が変わると端末側で上書きインストールできず、再インストールしたアプリは停止状態になりウィジェットプロバイダが動かず、ピッカーで「ウィジェットを追加できませんでした」になった。
- v0.17.0 でこの方式に移行。移行直後の1回だけ、端末側はアンインストール→再インストールが必要（アプリ内データは消える）。以後は署名が不変なので上書き更新できる。
- キーストアを失うと二度と同じ署名で出せなくなる。`.local/` のバックアップは本人の管理下に置くこと。
