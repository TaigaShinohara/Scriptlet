# Scriptlet UIカタログ

UIを作る／調整するときは、まずこのカタログから流用先を探す。新規パーツは「狙い」を添えてから作り、作ったらここへ登録する。方針の正本は ART_DIRECTION.md、値の正本は ui/Tokens.kt と ui/Theme.kt。

## 共通ルール

- カードの角丸は Tokens.CardRadius（16dp）、画面端と カード内の余白は 16dp、要素間は 8／12／16 の段でそろえる。
- 塗りボタン（Button）は1画面に1つ＝その画面の主役。相方は OutlinedButton か TextButton に降格する。
- 選択中は「2dpピンク枠＋primaryContainerの淡色＋✓」の3点セットで示す（色だけに頼らない）。

## パーツ一覧

| パーツ | 役割 | 使う場面／使わない場面 | 状態 | 狙い（方針との対応） |
| --- | --- | --- | --- | --- |
| スクリプトカード（ScriptCard） | スクリプト1件の要約と入口 | 一覧画面のみ。設定画面の選択カードとは別物にしない（形は共通） | 通常／メニュー展開 | 名前が主役、要約と更新日時は補助。「自分の道具が並んでいる」感覚 |
| 選択カード（設定画面） | ウィジェットに載せるスクリプトの選択 | 配置設定画面。単一選択専用 | 通常／選択中（枠＋淡色＋✓） | 選んでいる実感を色以外でも伝える |
| 実行プレビュー（WidgetPreview） | スクリプトの実行結果の描画 | 編集画面・設定画面（外枠つき）・拡大ダイアログ。描画そのものは不変が契約 | 成功／エラー（別カード） | 中身が主役。枠は静かに |
| 塗りボタン（主役） | その画面の決定・実行 | 編集＝▶実行プレビュー、設定＝この内容で決定、オンボーディング＝つぎへ／作ってみる | 通常／無効（未選択時） | ピンクは主役だけ（方針「色の性格」） |
| アウトラインボタン（相方） | 主役に次ぐ行動 | 編集＝ホーム画面に追加、最終ページ＝一覧から始める | 通常 | 主役を邪魔せず、でも確かに押せる |
| フィルターチップ（FilterChip） | 見た目の選択肢（背景色・余白・角丸・文字） | 設定画面の「見た目（任意）」のみ | 選択中／通常 | 任意項目は軽い部品で。主役にしない |
| 拡張FAB「＋ 新規」 | 新規作成の入口 | 一覧画面のみ | 通常 | 一覧の主役アクションはこれ1つ |
| 窓ドット | オンボーディングの進捗 | オンボーディングのみ（mobile_onboarding管理） | 現在／端 | 総数を数えさせない |
| ヒーローモック（HomeMock等） | オンボーディングの視覚の主役 | オンボーディングのみ | — | スレート色の「ホーム画面の世界」をアプリ枠と分ける。電話の枠の角丸（28dp）は「電話という物」の形で、カードの 16dp とは別扱い |
| ダイアログ（AlertDialog） | 選択・入力・確認の受け皿 | 新規作成の選択、名前変更、削除確認。モーダルが必要な場面だけ | — | 決定は TextButton、破壊的操作（削除）は文言で明示。塗りボタンは置かない（主役は元の画面に残す） |
| コンテキストメニュー（⋮） | カード・画面の副次操作の置き場 | 一覧カード、編集画面。主操作は入れない | 展開／閉 | 主役を隠さないための「畳む」先。開く・追加・複製・名前変更・削除の順 |
| 保存状態ラベル | 自動保存の状態表示 | 編集画面の上部 | 保存済み（✓）／編集中 | ボタンを廃止した代わりの安心材料。色は補助色（onSurfaceVariant）で主役にしない |
| 空状態メッセージ | 一覧が空のときの案内 | 一覧画面（0件時） | — | 「ない」ことと次の行動（＋から作成）を1行で。色は補助色で静かに |
