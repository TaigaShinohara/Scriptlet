# Scriptlet

JavaScript を書くと、そのまま Android のホーム画面ウィジェットになる基盤アプリ。

スクリプトは描画ツリー（JSON）を返すだけ。描画はアプリ側が Jetpack Glance で行うので、スクリプトは表示内容に集中できる。fetch によるデータ取得、Canvas 描画、端末内ストレージ（読み書き）もスクリプトから使える。

## できること

- スクリプトの作成・編集・その場で実行プレビュー
- サンプル9本（時計、カレンダー、天気ダッシュボード、カウントダウン、円グラフなど）から始めて、そのままホーム画面に配置
- ウィジェットごとの見た目設定（背景色・余白・角丸・文字サイズ）と、設定画面での外枠つきライブプレビュー
- 初回オンボーディング（選んだ「作りたいもの」に合わせてサンプルと進み方が変わる）

## 仕組み

- JS エンジン: QuickJS（quickjs-kt）
- スクリプトは描画ツリー（JSON）を返し、アプリが Glance / RemoteViews へ変換して描画する
- データ取得口は差し替え可能な設計で、特定サービスの固有処理は本体に入れていない

## ビルド

必要なもの: JDK 21、Gradle 8.9、Android SDK（compileSdk 36）。

```sh
gradle assembleDebug
```

（Gradle Wrapper は未同梱。Gradle 8.9 を直接使う。）

## 設計ドキュメント

- `docs/ART_DIRECTION.md` — UI のアート方針（色の役割・形・余白の決め事）
- `docs/UI_CATALOG.md` — UI パーツのカタログと流用ルール
